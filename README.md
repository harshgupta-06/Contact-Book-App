# 📞 Contact Book App

A simple and user-friendly **Contact Book Application** built using **HTML, CSS, and JavaScript**.  
This project allows users to **add, edit, delete, and search contacts**, and stores data permanently using **localStorage**.

---

## 🚀 Features

- ➕ Add new contacts (Name, Phone, Email)
- ✏️ Edit existing contacts
- 🗑️ Delete contacts with confirmation
- 🔍 Search contacts by name or phone number
- 💾 Data stored using **localStorage**
- 📱 Responsive and clean UI

---

## 🛠️ Technologies Used

- **HTML5**
- **CSS3**
- **JavaScript (DOM Manipulation)**
- **localStorage**
